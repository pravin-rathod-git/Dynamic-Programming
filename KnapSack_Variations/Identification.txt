✅ STEP 1 — Read the Problem Carefully

Identify:

📦 What is given?
Items
Weights
Coins
Lengths
Values
🎯 What is asked?

Minimum cost?
Possible or not?
Number of ways?
✅ STEP 2 — Ask the MOST IMPORTANT QUESTION
🔥 “Can an item be used multiple times?”

This identifies the main category.

✅ STEP 4 — Identify the DP Dimensions

Most Knapsack Problems use:

dp[n][W]

📌 Meaning
n → number of items
W → target/capacity
✅ STEP 5 — Identify the Core Pattern
🔥 “Take or Not Take”

Every knapsack problem is based on:

dp[i][j]=takeornot take

⚡ FAST IDENTIFICATION TRICKS
🔵 If Question Says:
“Select”
“Choose subset”
“Partition array”
➜ Mostly 0/1 Knapsack
🟢 If Question Says:
“Coins”
“Cuts”
“Ways to make amount”
➜ Mostly Unbounded Knapsack
🟣 If Question Says:
“Possible?”
“Can we achieve?”
➜ Boolean DP
🟠 If Question Says:
“How many ways?”
➜ Counting DP

🚀 INTERVIEW SHORTCUT

Whenever you see a DP problem, ask:

✅ 1. Can items repeat?
✅ 2. Need Max/Min/Count/Bool?
✅ 3. Is there a target/capacity?
✅ 4. Is Take/Not-Take possible?

If YES → It is probably Knapsack DP.
